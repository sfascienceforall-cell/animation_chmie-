Le 1er degré

ax + b

a est la pente  ·  b est l'ordonnée à l'origine

Une droite coupe l'axe une fois

ax + b = 0  →  x = − b ÷ a

Le 2e degré

ax2 + bx + c

a donne le sens  ·  c est l'ordonnée à l'origine  ·  b décale le sommet

La condition qu'on oublie

Si a = 0, il n'y a plus de terme en x2 : ce n'est plus du 2e degré, c'est une droite. a ≠ 0 fait partie de la définition.

Δ = b2 − 4ac

les coefficients de ax2 + bx + c, avec a ≠ 0

Δ > 0 — deux racines distinctes

La parabole coupe l'axe en deux points  ·  x = (−b ± √Δ) ÷ 2a

Δ = 0 — une racine double

La parabole est tangente à l'axe  ·  x = −b ÷ 2a

Δ < 0 — aucune racine réelle

Elle ne touche jamais l'axe et garde le signe de a partout.

Forme générale

x2 − 4x + 3

donne le sens (signe de a) et l'ordonnée à l'origine

Forme canonique

(x − 2)2 − 1

donne le sommet et l'axe de symétrie

Forme factorisée

(x − 1)(x − 3)

donne les racines — n'existe que si Δ ≥ 0

La phrase qui remplace le calcul

Un trinôme est du signe de a partout, sauf entre les racines.

Et si Δ < 0 : du signe de a partout, sans exception — il n'y a pas d'« entre ».
