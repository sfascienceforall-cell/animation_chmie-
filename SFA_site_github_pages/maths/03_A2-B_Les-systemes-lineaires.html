La question posée par une équation

« x + y = 4 » ne demande pas un nombre : elle demande tous les couples (x ; y) qui la vérifient.

On isole y pour pouvoir choisir x

x + y = 4  →  y = 4 − x

Les points s'alignent — et ce n'est pas un hasard

L'équation est du 1er degré : son graphe est une droite. Tout point de d₁ la vérifie, aucun autre point du plan.

Deuxième équation, même procédé

x − y = 0  →  y = x

D'où vient la solution du système

Le couple qui vérifie les deux équations est sur les deux droites : c'est donc leur intersection.

Un système, c'est deux droites

x + y = 4
x − y = 0

Sécantes — une solution unique

Le couple solution est le point d'intersection : x = 2 et y = 2.

Parallèles — système impossible

Aucun point commun, donc aucune solution.

Confondues — système indéterminé

Les deux équations décrivent la même droite : une infinité de solutions.

Reconnaître sans tracer

On compare les rapports des coefficients. Proportionnels et constantes proportionnelles → confondues. Proportionnels mais pas les constantes → parallèles.

3x − y = 8

Le principe

On élimine la même inconnue entre deux paires de lignes pour se ramener à un système 2 × 2.

La discipline d'écriture

Une ligne par étape, l'opération notée en marge. Un 3 × 3 se perd rarement sur le calcul, presque toujours sur l'organisation.

Détecter l'impasse

Une ligne devient « 0 = un nombre non nul » → impossible.
Une ligne devient « 0 = 0 » → indéterminé.
